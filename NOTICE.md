# Avisos de terceiros — Soma 3D Web Slicer

Este projeto é distribuído sob **AGPL-3.0** (ver `LICENSE`). Código-fonte: https://github.com/gruposoma3d/Soma-slicer

Componentes de terceiros:

- **OrcaSlicer** (AGPL-3.0) — https://github.com/OrcaSlicer/OrcaSlicer — motor de fatiamento e perfis de impressora (Creality, tag v2.4.2).
- **OrcaWasm** (AGPL-3.0) — https://github.com/Hiosdra/OrcaWasm — compilação do OrcaSlicer para WebAssembly (release `wasm-v2.4.2-patch29-multithreaded`, baixada no deploy). Seus avisos de terceiros (OCCT, oneTBB, libnoise e demais) estão em https://github.com/Hiosdra/OrcaWasm/blob/main/NOTICE.md
- **coi-serviceworker** v0.1.7 (MIT, © 2021 Guido Zuidhof) — https://github.com/gzuidhof/coi-serviceworker — `site/coi-serviceworker.js`.
